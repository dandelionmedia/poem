청소년의 해석 새로운 감각으로 다시 만든 시화

우리가 만드는 것은 ‘그림 설명’이 아니에요

세대공감 시화는 시 속의 감정과 의미를 청소년의 시선으로 다시 바라보는 활동입니다.

GENERATION BRIDGE
단순 삽화 “시에 나온 장면을 그대로 그려야지.”

시 속에 나오는 사람, 장소, 사물을 하나씩 설명하듯 표현하는 방식입니다.

세대공감 시화 “이 시를 읽고 내 마음에는 어떤 느낌이 남았지?”

어른의 경험을 청소년이 자신의 감정과 색감, 상징으로 다시 해석하는 방식입니다.

어른의 기억이 청소년의 상상력과 만나면, 같은 시도 전혀 새로운 한 장의 작품이 됩니다.

세대공감 시화를 만드는 4단계

읽기 → 공감하기 → 해석하기 → 시화·영상용 프롬프트 만들기의 흐름으로 진행해보세요.

4 STEPS
1

어른의 시 읽기

시 속에 담긴 시간, 기억, 사람, 감정을 천천히 느껴봅니다.

2

내 마음과 연결하기

나는 어떤 감정을 느꼈는지, 어떤 장면이 기억에 남았는지 생각합니다.

3

시화로 해석하기

상징, 색감, 여백, 글씨체를 골라 한 장의 시화로 표현합니다.

4

Flow용 프롬프트 만들기

9:16 이미지 프롬프트와 Google Flow 영상 프롬프트를 함께 만들어 콘텐츠로 확장합니다.

나만의 세대공감 AI 시화 프롬프트 만들기

한 번 입력하면 아래에 이미지 프롬프트 3종과 Google Flow 영상 프롬프트 2종, 총 5종이 함께 생성됩니다.

CREATE
✍️

어른의 시 + 나의 해석 입력

시의 원문과 내가 느낀 감정을 입력하면 시화용 프롬프트와 Flow용 프롬프트가 자동으로 완성됩니다.

시화를 만든 사람의 이름도 작품에 넣을 수 있어요.
예: 동성중학교 3학년 2반 한소민
입력한 문구를 작품 분위기에 어울리게 자연스럽고 잘 보이도록 넣는 프롬프트가 생성됩니다.
시 원문은 그대로!
이미지 안에는 입력한 창작시를 요약하지 않고 원문 그대로 넣도록 프롬프트가 만들어집니다.

시를 읽고 내 생각을 조금 더 적어보세요

정답은 없습니다. 아래 예시를 참고해서 내가 느낀 것을 편하게 적으면 됩니다.

예시 “네 속이 내 속인걸” · “엄마의 손이 생각나는 구절” · “다시 읽고 싶은 따뜻한 한 줄”
시 전체에서 가장 기억에 남거나, 마음이 움직였던 한 줄을 그대로 적어보세요.
예시 이해 · 그리움 · 화해 · 가족 · 위로 · 성장
예시 창가에서 조용히 밖을 바라보는 장면 · 두 사람이 마주 앉은 장면 · 노을빛 길을 함께 걷는 장면
영화의 한 장면을 떠올리듯 생각해보세요. 실제 시 내용과 똑같지 않아도 괜찮습니다.
얼굴을 크게 보여주지 않으면 보는 사람이 자신의 기억이나 경험을 더 쉽게 떠올릴 수 있습니다.
이미지·영상 비율 선택
각 결과물의 사용 목적에 맞게 원하는 비율을 선택해보세요.
AI 활용 이미지 생성 표시 선택
이미지 생성 프롬프트 3종(시화 이미지·북트레일러 표지·글자 없는 배경)에 “AI활용이미지생성” 문구를 넣을지 선택할 수 있습니다.
표시함을 선택하면 이미지의 핵심 내용과 시 글자를 방해하지 않는 모서리 여백에 작고 단정하게 배치됩니다.
이번 페이지에서 생성되는 결과
① 시화 이미지 프롬프트(글자 포함)
② 시화 북트레일러 표지 프롬프트
③ 배경 이미지 프롬프트(글자 없음)
④ Google Flow 영상 프롬프트(글자 포함 시화용)
⑤ Google Flow 영상 프롬프트(글자 없는 배경용)
Google Flow 활용 팁
글자 포함 시화 버전은 시 낭송 영상의 첫 장면이나 메인 장면에 적합하고,
글자 없는 배경 버전은 자막, 모션, 전환 효과를 나중에 얹는 장면에 특히 유용합니다.
시 글자 보존 강화
글자 포함 시화용 Flow 프롬프트는 시 제목·시인·시 원문·창작자 이름을 완전히 고정하고, 텍스트에는 줌·흔들림·모션 블러·빛 효과·재생성을 적용하지 않도록 강하게 설정했습니다. 움직임은 그림과 배경에만 제한합니다.
① 시화 이미지 프롬프트

선택한 비율의 시화 이미지 만들기

선택한 비율 안에 시 전문과 그림, 창작자 이름이 함께 들어가는 시화 이미지 제작용입니다.

입력 후 “프롬프트 5종 만들기”를 누르면 여기에 시화 이미지 프롬프트가 표시됩니다.
✓ 복사가 완료되었습니다.
② 시화 북트레일러 표지 프롬프트

선택한 비율의 시화 북트레일러 표지 이미지 만들기

북트레일러 첫 화면에 바로 사용할 수 있도록 대표 장면·제목 중심·영화 포스터형 시선 흐름으로 설계한 오프닝 표지 전용 프롬프트입니다.

입력 후 “프롬프트 5종 만들기”를 누르면 여기에 시화 북트레일러 표지 프롬프트가 표시됩니다.
✓ 복사가 완료되었습니다.
③ 배경 이미지 프롬프트(글자 없음)

선택한 비율의 배경 이미지 만들기 (글자 없음)

같은 시의 분위기를 유지하면서, 시·제목·작가·창작자 이름 없이 배경만 만드는 프롬프트입니다.

입력 후 “프롬프트 5종 만들기”를 누르면 여기에 배경 이미지 프롬프트(글자 없음)가 표시됩니다.
✓ 복사가 완료되었습니다.
④ Google Flow 영상 프롬프트

선택한 비율의 시화 이미지(글자 포함)를 영상으로 만들기

시 글자는 완전히 고정하고, 그림과 배경만 부드럽게 움직이도록 설계한 Flow용 프롬프트입니다.

입력 후 “프롬프트 5종 만들기”를 누르면 여기에 Google Flow 영상 프롬프트가 표시됩니다.
✓ 복사가 완료되었습니다.
⑤ Google Flow 영상 프롬프트

선택한 비율의 배경 이미지(글자 없음)를 영상으로 만들기

글자 없는 배경 이미지를 선택한 Flow 비율에 맞는 분위기 중심 영상으로 확장하는 프롬프트입니다.

입력 후 “프롬프트 5종 만들기”를 누르면 여기에 Google Flow 영상 프롬프트가 표시됩니다.
✓ 복사가 완료되었습니다.

완성된 작품에서 이것을 확인해보세요

정답을 찾는 활동이 아니라, 서로 다른 해석과 활용 방법을 발견하는 활동입니다.

CHECK
① 어른의 시가 그대로 담겼나요? 4:5와 9:16 글자 포함 버전에서 시 제목, 시인 이름, 시 원문이 정확하게 들어갔는지 확인합니다.
② 나의 감정이 보이나요? 색감과 상징에서 내가 느낀 감정이 드러나는지 봅니다.
③ 단순한 설명 그림은 아닌가요? 시의 모든 장면을 그대로 나열하지 않고 의미를 재해석했는지 봅니다.
④ 글자가 편하게 읽히나요? 글자 포함 버전은 시 원문과 그림이 겹치지 않고 가독성이 충분한지 확인합니다.
⑤ 창작자 이름이 잘 보이나요? 입력한 이름·소속이 정확하고 자연스럽게 들어갔는지 확인합니다.
⑥ Flow 영상으로 확장하기 좋나요? 시화 분위기에 맞는 부드러운 움직임, 카메라 워크, 자막 여백까지 고려되었는지 확인합니다.
같은 시, 다른 세대, 새로운 한 장의 이야기 어른의 경험을 청소년의 감각으로 이어보고, 시화 이미지에서 영상 콘텐츠까지 확장해보세요.
